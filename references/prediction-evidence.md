# 预测结论与证据对应

这是四源区分方式形成的**综合写作标准**，不是论文正确性的认证。K5–K8 提示轨迹、统计、成本应分开；F1–F4、D1–D4 提示理论对象与离散实现应分开；J2–J5 提示物理量、条件与检验应对应。锚点见 [sources.md](sources.md)。只检查文字涉及的行，不把下表变成强制实验清单。

## 最小证据记录

复用已有表或产物，记录足以复核的内容：`claim → metric/definition → split + independent unit → conditions/horizon → artifact or user-provided record → allowed scope`。公式/结构主张则记录假设、推导、实现或所引原文。

只有用户汇总数值时可据此写作，说明“依据用户提供汇总”，不声称重新计算或审计了原始数据。缺少非关键字段不阻断小段写作；划分或指标定义影响句意时，完成不依赖该项的内容并指出缺口。

| 想写的结论 | 直接依据与应明确条件 | 不能替代的证据 |
| --- | --- | --- |
| 一步准确 | 目标量、误差定义、归一化、测试单位及条件 | 训练损失、视觉相似；validation 不改叫 test |
| 多步准确/有效时域长 | 自回归或直接预测、逐时刻/窗口误差、时间单位/步长、阈值、失败处理 | 一步误差小、运行无报错、单个终点图 |
| 数值稳定 | 定义、测试跨度、发散/失败判据及比例 | 跑完不能证明渐近稳定或物理稳定 |
| 统计重现 | 统计量、采样/去瞬态窗口、独立轨迹及离散度 | 谱相近不证明单轨迹相位正确 |
| 守恒/物理/边界满足 | 相应离散恒等式或直接残差、区域、容差 | PDE loss 名称、低全局 L2、包含投影层 |
| 跨条件泛化 | 训练范围、测试变化、固定条件、是否重训/调参、独立单位 | 同轨迹随机拆帧、验证集、单个新点 |
| 零样本分辨率迁移 | 同一权重、训练/测试网格及采样、插值/重训情况、实测误差 | FFT 可执行、坐标可查询、插值图更密 |
| 更快/更便宜 | 基线、同等误差/网格/预算、硬件、精度、batch、计时范围、时域 | 仅 FLOPs、仅 forward、硬件/精度不同却省略条件 |
| 数据效率 | 数据单位、变化预算、相同评价、重复与适当不确定性 | 一个小训练集表现不错 |
| 机制导致改进 | 针对性对照/消融、固定混杂因素、对应诊断 | 场图、注意力图、关联变化 |
| 理论保证 | 定理、假设、空间/范数、量词、适用对象 | 有限数据训练、经验指数下降、数值稳定 |

## 具体边界

- **任务**：function-to-function 不必包含时间；重建、预测和控制不等同。先确定监督目标，再选写法。
- **独立单位**：帧、网格点、初值、轨迹不可互换；邻近帧不是自动独立的测试。按实际协议说明分组/时间划分。
- **误差**：relative L2 的范数范围、分母和跨样本汇总顺序保持一致；mean ± std 的来源是 seeds 还是测试样本必须说清，不将 std 叫作置信区间。
- **泛化**：跨初值、时间外推、参数、几何、分辨率分别命名。zero-shot 在所声称条件下未重训，不能隐去 finetuning。
- **成本**：`speedup = baseline_time / method_time` 仅在对象一致时计算；纯 forward 叫 inference/forward latency。训练和数据生成成本另列，不假装已摊销。跨硬件对照可报告，但硬件差异必须可见。
- **标度**：平均/峰值速度、直径/半径不能混用；它们影响 Re、无量纲时间、频率与流量。核对当前协议，不套样本参数。
- **参考**：DNS、LES、粗化数据和实验观测按来源命名，不自动升级为 ground truth。与参考的一致性不等于已验证物理精度。
- **机制诊断**：使用 DMD/谱等时，只报告实际诊断支持的可辨识对象；不存在的模式、未算窗口不能由写作补齐。这不意味着每篇预测论文必须做此类分析。

## 缺证据时仍推进

支持单步就写单步，未测 rollout 不声称稳定。已测失败影响主张时，按下节科学变更规则处理贡献范围并呈现相关结果，不以“未来完善”掩盖缺口。只有方案时输出方法/计划，明确计划身份。

语言改写使用现有事实，不要求为润色重跑实验。需要新分析才能回答问题时，在正文外列出待补证据及用途；仅在用户授权后进入执行。

## 科学变更与作者授权

纯语言任务保持数字、划分、比较方向、证据强度与适用范围。发现科学问题时，指出具体位置、所给证据与表述之间的差距，提供候选改法和影响；完成不受影响的文字。缺少材料表示当前不能判断，不等同已证明主张错误。

删除或削弱核心主张、删去不利比较、改变成本分母、合并不同泛化范围、把解释改为因果，均不是普通润色。先判断当前授权是否包含该项实质修改：已明确授权则落实并说明；未授权时保留原文件中的相关主张待作者决定，交付建议，不把它作为已核实结论重新肯定。只审查不写文件。语法、指代、空泛包装等不改变含义的修改可直接完成。

不能借“保留原意”认可明显错误，也不能把每个表述疑点扩大为代码审计或新实验。正文忠实报告已完成的不利结果和必要条件；未执行的检验写在交付说明或用户要求的计划中。
