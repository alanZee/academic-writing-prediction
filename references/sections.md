# 章节动作：只读当前部分

这是四源的可迁移组织方式，不是期刊格式。J/K/F/D 锚点见 [sources.md](sources.md)，核心动作见 [style.md](style.md)。服从当前投稿要求，不机械复制 JFM 的两组 Results、PNAS Significance 或 ICLR 版面。

## 大纲与主线

完整结构设计先读 [argument-architecture.md](argument-architecture.md)：从科学问题和知识目标出发，设计候选主张、证据需求与判定标准；再按实际证据确立核心 claim，分配章节职责，安排段落与句间关系。下列三种路径只是导航；四篇原文的具体安排和WHY见其逐篇细读，不是三种固定提纲。

有结果时，用已有证据写出“在什么问题中，改变什么，支持哪个发现”；设计阶段则说明“要获得什么认识、准备检验什么、需要哪些证据”。围绕问题和回答安排正文，已实现模块按其论证作用进入方法。

- 物理导向（J1/J3–J6）：问题定义 → 分析依据 → 据此提出的方法 → 预测表现 → 对解释的独立检验。
- 数值导向（K1–K8）：任务与瓶颈 → 学习/固定部分 → 精度 → 匹配条件的成本 → 适用范围。
- 算子导向（F1–F4 / D1–D4）：函数映射 → 表示与假设 → 离散训练 → 准确性与条件变化。

支持核心主张的分支才进入主线。已完成的不利比较若影响核心结论，按[科学变更边界](prediction-evidence.md#科学变更与作者授权)处理贡献并如实呈现，不能删除比较以制造普遍优越性。

先确定数据和图表能回答什么，再写 Results，最后核对引言、摘要、结论。用户明确“先图后文”时遵从该阶段，图表规划不算完成证据。

## Title / Abstract

标题点出预测对象或方法改变，必要时限定系统，不堆 accurate、efficient、robust。摘要可按问题及范围 → 技术改变 → 关键结果及比较条件 → 有限适用意义组织（J1、K1、F1、D1）；也可先呈现核心发现，再补理解所需的问题和方法，具体顺序与篇幅遵从内容及期刊要求。

只留下有证据的定量结果；不从图像观感补数字，不从单步验证升级为长时预测。方法性贡献无需硬塞倍率。

## Introduction / Related work

用 J1 的物理问题收束或 K1 的瓶颈定位开题；F1/D1 的函数到算子区别只用于真正学习算子的研究。

按科学关系综述，如预测时域、输入条件、约束处理、评价对象。写前人做了什么及其条件，再说本研究要回答什么。不把作者名单与方法清单当论证，不把样本文献的参考文献转抄成自己已核读的来源。

把既有认识中的未知落到研究目标，再引出方法选择与证据支持的贡献；模型构建和实验执行是工作内容，需说明它们带来什么认识或能力。结尾给实际贡献和必要导航。未经文献核查不用 no prior work / first；新颖性采用定向检索，不要求每次润色重新做完整综述。

## Problem formulation / Methods

借鉴 J2、K2–K4、F1–F3、D1–D3，按理解依赖组织以下信息；编号不规定段落数量或唯一顺序：

1. 物理系统、控制方程、边界/初值、标度；或静态算子输入与解空间。
2. 输入信息、预测量、时间索引及输出求值方式；区分一步、自回归、直接时空预测、稳态映射。
3. 学习部件与固定操作；符号在首次使用时配有定义或可识别的回指，关键公式可紧接解释，说明操作为何与问题有关。
4. 训练目标、采样/划分、部署方式与影响重现的设置；不用未展示的性能结论收尾。

关键假设和实现边界留正文，次要配置可放附录。理论原文只在确切条件内引用，不能将动机写成自己的新定理。

## Results / Experiments

每小节回答一个支撑核心 claim 的问题，并交代其与研究目标的关系。按实际证据完成观察、比较、解释与结果定性，区分预设检验和探索分析。标题应覆盖本节核心比较，例如 One-step and rollout accuracy，但必须真的有相应实验；不能只点出有利的一项而掩盖同节主要对照。

让问题或发现、必要比较条件及图表与定量证据形成清楚的关系。可先给条件或先给发现；段尾仅在需要综合或承接时补结论，不重复已经明确的判断。J3–J5 提供现象到针对性检验的组织，K5–K8 提供指标分工；不必每段重复全套数据设置。

按主张择取，不强制全做：参考可信度、主要精度、多步误差/有效时域、物理/统计量、效率、单因素消融、分布变化。静态任务不强加 rollout。参考解验证缺失时，所测只能表述为与指定参考的一致程度。

Results 是否包含简短解释遵从当前期刊与项目要求。解释紧邻支持证据并与观察区分；未检验机制放讨论并标为推断。漂亮流场图不代替误差或统计检验。

## Figures / Tables / Captions

借鉴 J3–J5 和 K5–K8，令每个面板有证据职责。跨方法采用一致变量、色标或说明差异，不为显示优势更改比较范围。

图注按对象/条件 → 面板量 → 参照与归一化 → 线型/符号 → 平均、离散度或窗口含义组织，只写适用信息。裁剪、案例选择和误差带含义透明，结论不能超图中证据。

没有图表时可准备需求和文字结构，不能引用不存在的 Fig. 1 或补虚拟曲线。用户授权绘图后才进入可用制图流程。

## Discussion / Conclusion

讨论按已建立发现 → 解释与替代解释 → 与前人关系 → 有证据的条件组织（J6、K8、D4）。长期统计不改称轨迹逐点一致；训练摊销或维度外推单独声明假设。

结论回答引言问题，说明研究目标实现到什么范围，以及所得认识或方法能力相对已有工作的增量。删除无依据宣传并重构论点，不用含糊免责声明维持旧结论。尊重当前用户/期刊对限制或未来工作章节的安排，不将某项目章节禁令扩展为全局规范，也不隐去影响主要结论的证据。
